# Références

Le fichier `references.bib` est la bibliographie canonique. Employer des clés stables, des métadonnées complètes et les DOI ou URL de l’éditeur lorsque disponibles.

Avant d’ajouter une source, vérifier qu’elle existe, qu’elle soutient effectivement l’affirmation citée et que la référence n’existe pas déjà sous une autre clé. Pour une documentation vivante, enregistrer le produit, la version et la date de consultation dans le chapitre.
