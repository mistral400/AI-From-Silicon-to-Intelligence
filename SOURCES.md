# Politique des sources

## Choix des sources

Privilégier les sources primaires et stables : articles de recherche, spécifications, documentation officielle, jeux de données et dépôts de code originaux. Les sources secondaires sont utiles pour le contexte et doivent être identifiées comme telles.

## Citations

- Chaque affirmation technique non élémentaire reçoit une citation au plus près du texte.
- Les citations utilisent une clé BibTeX stable, par exemple `[@vaswani2017]`.
- Les citations bibliographiques sont ajoutées à `references/references.bib`; ne pas réutiliser une clé pour un autre document.
- Une source consultée sur le Web conserve son URL, sa date de publication lorsqu’elle est connue et sa date de consultation si le contenu peut changer.
- Distinguer résultats publiés, documentation fournisseur, mesures personnelles, estimations et hypothèses.

## Vérification

À la rédaction, ouvrir la source et vérifier qu’elle soutient bien l’affirmation. Pour logiciels et modèles vivants, noter version/date. Signaler les désaccords entre sources et les limites de mesure. Ne pas inférer une spécification confidentielle d’un modèle à partir de rumeurs.

## Droits d’auteur

Reformuler avec ses propres mots; ne pas reproduire de longs passages. Pour une figure externe, vérifier les conditions de réutilisation avant l’inclusion. Les figures créées pour le projet doivent être originales ou clairement attribuées.
